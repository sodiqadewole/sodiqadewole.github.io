# Local Qwen Research Agent with SmolAgents

This project documents the notebook that builds a local research agent with SmolAgents, Qwen2.5, and web search.

## Components

- `ToolCallingAgent` for tool-mediated research.
- `DuckDuckGoSearchTool` for retrieval.
- Research tasks across fact lookup, comparison, trend analysis, and investigative synthesis.
