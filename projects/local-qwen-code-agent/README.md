# Local Qwen Code Agent with SmolAgents

This project documents the notebook that builds a local code-execution agent with SmolAgents and `Qwen/Qwen2.5-0.5B-Instruct`.

## Components

- `CodeAgent` for generating and executing Python code.
- `TransformersModel` for local model inference.
- Evaluation prompts for arithmetic, ranking, text analysis, algorithms, and tabular summaries.
